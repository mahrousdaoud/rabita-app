# خدمة الرياضة بمصر — Rabita App

تم تحديث المشروع ليعمل كمنصة فرق مستقلة على Firebase/Firestore.

## أهم التعديلات
- الاسم: **خدمة الرياضة بمصر**.
- اللوجو الجديد المستخرج من ملف الخدمة.
- صفحة الرؤية والرسالة والقيم وإقرار الإيمان بعد التسجيل مباشرة.
- صفحة **اللائحة** مستقلة.
- فصل **اللقاءات** عن **الأحداث**.
- إضافة المكان لكل لقاء/حدث.
- زر **فوت — أكّد حضورك المتوقع**.
- اعتذار خاص بسبب يصل لقادة فريق العضو فقط.
- مجموعة مستقلة لكل فريق للنصوص والصور.
- الطالب يرى فريقه فقط في بيانات الفريق والمنشورات.
- حذف الطالب وتفاصيل الطالب الكاملة.
- عدة أدمنية لنفس الفريق.
- أدمن المدرسة مع إمكانية إنشاء مدارس مستقبلًا.
- لوحة إحصائيات.
- تغيير العشور إلى **التعهد**.
- رقم كاش مستقل لكل فريق، مع رقم ديرمواس الافتراضي: `01282802083`.
- صلاحيات Firestore محدثة بحيث لا يستطيع قائد فريق تعديل بيانات فريق آخر.

## ملاحظة مهمة للصور
المجموعة تدعم رفع الصور عبر Firebase Storage. يجب تفعيل Storage في مشروع Firebase مرة واحدة، ثم نشر `storage.rules`.

لا توجد أي مكتبة Node.js جديدة مطلوبة في المشروع؛ الاعتماديات الأصلية موجودة بالفعل في `package.json`.

## تحديثات النسخة المعدلة

- التسجيل أصبح بأربع فئات: قائد، مدرسة الدفعة الأولى، مدرسة الدفعة الثانية، مدرسة الدفعة الثالثة.
- إضافة تاريخ الميلاد أثناء التسجيل، وإنشاء سجل عام آمن لتواريخ الميلاد لإظهار تنبيهات أعياد الميلاد.
- دعم العربية والإنجليزية من زر اللغة في الواجهة.
- إصلاح/تقوية تأكيد الحضور والاعتذار مع صلاحيات Firestore مناسبة.
- إضافة أدمن مخصصين لاستقبال الاعتذارات من لوحة الإعدادات.
- إضافة مجموعة خدمة تتيح لكل عضو إرسال رسالة أو صورة، مع ظهور اسم المرسل وإمكانية التعليق على الرسائل.
- إضافة Blacklist تمنع العضو المحجوب من الوصول إلى محتوى المنصة، مع إمكانية إزالته من القائمة.
- إضافة قسم الأحداث، مع زر لإضافة الأحداث الأساسية الستة تلقائيًا: مدرسة m power، مدرسة impact، مدرسة Scaleright، مدرسة الأعضاء الجدد، أولومبيات القادة، قعدة رجالة.
- إضافة تنبيه عيد الميلاد في الصفحة الرئيسية وشارة أعلى المنصة.
- تحديث `firestore.rules` و`storage.rules` لدعم الميزات الجديدة.

> بعد تنزيل المشروع شغّل `npm install` ثم `npm run build`. وبعد التأكد من البناء، انشر القواعد عبر `firebase deploy --only firestore:rules,storage` ثم انشر الاستضافة.
