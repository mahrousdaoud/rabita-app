# الرابطة الإنجيلية لفريق الخدمة بالرياضة — النسخة المعدلة

## التعديلات الموجودة
- التسجيل أصبح: قائد / مدرسة الدفعة الأولى / مدرسة الدفعة الثانية / مدرسة الدفعة الثالثة.
- إضافة تاريخ الميلاد مع التسجيل.
- اللوجو داخل إطار أبيض فاتح في الواجهة.
- إصلاح منطق تأكيد الحضور والاعتذار مع رسائل خطأ أوضح.
- مجموعة عامة: كل عضو يقدر يرسل نصًا أو صورة، والاسم والصورة الشخصية يظهران للكل.
- إضافة قسم «أحداثنا» مع: مدرسة m power، مدرسة impact، مدرسة Scaleright، مدرسة الأعضاء الجدد، أولومبيات القادة، قعدة رجالة.
- إضافة زر تبديل عربي / English في الشريط العلوي.
- إضافة بلاك ليست من لوحة الأدمن: العضو المحجوب لا يستطيع الوصول لمحتوى المنصة.
- إضافة أدمن مخصص للاعتذارات من الإعدادات.
- إضافة إشعار داخل المنصة لأعياد الميلاد غدًا.
- إضافة مزامنة لأعياد الميلاد للأعضاء الحاليين من لوحة الأدمن.
- تحديث Firestore/Storage Rules للصلاحيات الجديدة.

## مهم بعد رفع الكود
ارفع القواعد الجديدة إلى Firebase:

```bash
firebase deploy --only firestore:rules,storage
```

ثم ابنِ وارفَع الموقع:

```bash
npm install
npm run build
firebase deploy --only hosting
```

> لو `npm install` لم يكتمل عندك، احذف `node_modules` و `package-lock.json` فقط إذا كنت محتاج إعادة تثبيت كاملة، ثم شغل `npm install` من جديد.

## أول إعداد بعد الدخول كأدمن
1. افتح «الإعدادات والبلاك ليست».
2. اختر الأشخاص الذين تريد أن تصل لهم الاعتذارات.
3. اضغط «مزامنة أعياد الميلاد» مرة واحدة للأعضاء الموجودين بالفعل.
4. من «الأحداث» أضف مواعيد الأحداث الفعلية وتاريخها؛ أسماء الأحداث الجاهزة موجودة كاختيارات.
